# 📝 Notes Saver App

A clean and modern **Notes / Paste Saver application** built using **React, Redux Toolkit, React Router, and Tailwind CSS**.  
This app allows users to create, edit, view, search, copy, share, and delete notes — with persistent storage using the browser.

---

## 🚀 Live Demo

👉 (https://notes-saver-app.vercel.app/ )

---

## ✨ Features

- Create new notes / pastes
- Edit existing notes
- View notes in read-only mode
- Search notes by title
- Copy notes to clipboard
- Share notes using Web Share API
- Delete notes
- Persistent storage using `localStorage`
- Clean & aesthetic UI
- Fully responsive layout
